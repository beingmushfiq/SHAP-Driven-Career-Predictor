About the Project

Thesis Title

SHAP-Driven Feature Importance Analysis of XGBoost for Explainable Localized Career Prediction Using Academic and Soft-Skill Data

Methodology

  • 1
    Data Ingestion: Merging disparate datasets containing student academic records, hackathon participations, and psychological soft-skill traits.
  • 2
    Pipeline Engineering: Robust preprocessing using LabelEncoding and schema locking to ensure inference consistency.
  • 3
    Gradient Boosting: Implementation of XGBoost with stratified hyperparameter tuning to handle multi-class career labels.
  • 4
    Explainable AI (XAI): Integration of SHAP TreeExplainer to break down the "black box" model into interpretable additive feature contributions.

Technologies Used

Python 3.14 XGBoost SHAP Django 6.0 Scikit-Learn Pandas Matplotlib Bootstrap 5
